# Pregnancy cover team constructor

Командный production-конструктор обложек курса `#sekta курс для беременных`.

## Что входит

- 79 базово собранных proposal-обложек;
- 16 сохранённых визуальных баз из выбора Оли;
- 94 production-safe фотографии без двух чувствительных кадров;
- прямое перемещение заголовка, lockup, метаданных, плашки и кругов;
- четыре параллельно редактируемые монтажные системы: световая сцена, плашка, split и крупная типографика;
- независимые кроп, масштаб, яркость, контраст и насыщенность фотографии;
- режим расширения студийных кадров с мягко наращёнными боковинами;
- отдельная перекраска верхней и акцентной строк логотипа, включая фирменные свотчи и произвольный HEX;
- включение и выключение метаданных, плашки, кругов, линий и градиентного затемнения;
- локальное автосохранение полного рабочего state;
- JSON проекта для продолжения работы на другом устройстве;
- PNG 2560 × 1440 текущего материала;
- ZIP для агента: 79 review-PNG, manifest JSON/CSV, инструкции, полный project JSON и карта исходников;
- подключение локальной папки оригиналов для финального рендера без загрузки файлов в интернет.

## Сохранение и передача

GitHub Pages — статическая страница. Автосохранение хранится в `localStorage` конкретного браузера и не синхронизируется между устройствами. Для передачи смены используйте `Экспорт JSON` / `Импорт проекта`.

`ZIP для агента` не меняет статус материалов. Цепочка остаётся честной: `proposal → selected → review candidate → approved → published`.

## Медиатека и приватность

В Pages-пакет входят только 94 production-safe browser masters. Два чувствительных кадра о родах/восстановлении исключены из публичного репозитория. Исходный локальный архив не публикуется: оператор может подключить папку оригиналов через браузер, после чего конструктор использует совпавшие оригинальные файлы для финального 2K-рендера в текущей вкладке.

## Локальный запуск

Откройте `index.html` или запустите любой статический HTTP-сервер в этой папке.

`index.html` публикует актуальную carrier-first версию v6. Предыдущий v5 сохранён отдельным архивным файлом.
