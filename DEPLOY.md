# GitHub Pages deployment

Пакет публикуется из репозитория `OLYMARKES/preg`.

1. Обновить `index.html` актуальной production-версией конструктора.
2. Отправить изменения в ветку `main`.
3. Workflow `.github/workflows/pages.yml` опубликует `index.html`, шрифты, data-файлы и 94 production-safe изображения.

Перед публичной отправкой требуется отдельное подтверждение владельца фотографий: GitHub Pages и публичный GitHub-репозиторий делают вложенные изображения доступными по прямым URL. Чувствительные кадры уже исключены технически.
